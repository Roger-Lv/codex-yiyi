# 依一

依一是一只蓝金渐层小母猫。她有圆圆的灰绿色眼睛和粉鼻头，打招呼时会举起前爪，露出肉垫和一点舌尖。

![依一抬爪打招呼](previews/waving.gif)

这套 Codex 桌面伙伴包含 9 组动作和 16 个注视方向。空闲时她会慢慢眨眼，工作时低头踩奶，等待回应时会抬起下巴。[观看完整动画](previews/all-states.mp4)

## 安装

1. 下载并解压[安装包](https://github.com/Roger-Lv/codex-yiyi/archive/refs/heads/main.zip)。
2. 将包内的整个 `yiyi` 文件夹复制到 Codex 的 `pets` 目录。macOS 和 Linux 默认在 `~/.codex/pets/`，Windows 默认在 `%USERPROFILE%\.codex\pets\`。如果设置了 `CODEX_HOME`，请使用该目录下的 `pets` 文件夹。
3. 重新打开支持自定义伙伴的 Codex 桌面客户端，在伙伴选择器中选择「依一」。

安装后，`pets/yiyi/pet.json` 和 `pets/yiyi/spritesheet.png` 应当位于同一层目录。
